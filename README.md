# 班导师模块 · 可点击 HTML 原型

按学工系统源码（`学工系统代码/znzhxgpt-yw`、`znzhxgpt-code`、`znzhxgpt-uni`）和线上系统（只读核对）复刻的班导师模块原型，用于演示和后续需求迭代。所有数据均为仿真假数据。

## 一、打开方式

| 入口 | 说明 |
|---|---|
| `index.html` | PC 端（布局、导航、菜单、页签与线上一致） |
| `mobile.html` | 移动端（手机外框，左侧可切换角色和快捷跳转） |

- 双击即可离线打开（`file://`），不需要服务器，不联网（Vue / Element Plus 已放在 `lib/`）。
- 也可以起一个本地静态服务，例如 `python3 -m http.server 8765`，然后访问 `http://localhost:8765/index.html`。
- 演示数据存在浏览器 `localStorage`（键 `bds_proto_data_v1`）。PC 端和移动端共用同一份数据，在 PC 端改班导师带班后，移动端立即可见。注意：`file://` 打开和 `http://` 打开是两个独立的存储空间，数据不互通。
- 恢复初始数据：PC 端点右上角头像 → 「重置演示数据」；移动端点「我的 → 重置演示数据」或左侧按钮。
- 切换角色：PC 端点右上角头像，选择角色；移动端点「我的 → 切换角色」或用左侧下拉框。

### 带班履历、证明、提醒、医学口、评选专干

- **带班履历**存在 `state.bdsRz`（班级、学年、开始日期、结束日期）。结束日期为空表示仍在任，界面和证明里显示「至今」。当前带班由未结束记录派生，并同步回 `bds.bjbhList`。添加带班要选择学年、开始时间和结束时间：班级管理「添加班导师」，以及班导师名单新增/编辑里新绑定的带班班级，学年和开始时间必填；结束时间可空，空表示仍在任，填写则按该日期固化为历史段。同一班导师对同一班级可以有多段互不重叠的履历。是否重叠按所选开始、结束时间判断。同一时期一个班只能有一名班导师；一名班导师同一时期最多带两个班。移除只给当前在任记录写结束日期，历史不删。班导师列表、详情、个人信息里的当前带班班级展示学年和起止时间；历年各段在详情和个人信息的「历年带班」中查看。证明里的任职时间用履历上的开始、结束日期。名单可按学年或任职区间查看「同期带班数」。读取旧数据时若缺学年，按开始日期补上，不因此升高存储版本。
- **工作证明**：原件在 `assets/班导师证明模板.docx`。名单工具栏「下载空白证明模板」下载这份未填写的原件。详情或名单行「导出证明」按同一版式生成并下载 `.docx`（浏览器内打包，不依赖外网，Word / WPS 可打开）。填写栏位：标题和正文里的学院（`bds.szxy`，模板「XX」是学院名去掉末尾「学院」）、表格中的姓名、工号、所带班级、任职班导师时间（`YYYY年MM月-YYYY年MM月`，结束日期为空写「至今」）。历年带班用该工号在 `state.bdsRz` 中的全部记录（含已结束，按开始日期从早到晚，一段任职一行），不只当前在任。考核情况原型没有逐段结果，导出留空，供盖章前手填；空白模板该栏仍是「优秀/合格/不合格」。落款保留学院副书记签名、学院（盖章）、学工部证明人签名、中南大学学生工作部（处），签名处留白。
- **一键提醒**（仅学工部管理员，班级管理工具栏）：找出没有在任班导师的班级，按辅导员归并，预览后发送。写入 `state.messages`，辅导员在「我的待办 › 系统消息」可见。消息全文：

  标题 / ITS 待办：【智慧学工】请尽快为未绑定班导师的班级指定班导师

  正文：`{辅导员姓名}老师：` 换行 `您所带班级中有 {N} 个尚未绑定班导师：{班级名称}。` 换行 `请在「基础信息 - 班级管理 - 管理班级 - 班导师列表」中完成绑定。一个班仅一名班导师，一名班导师同时最多带两个班。` 换行 `党委学生工作部`

- **手动录入**：新增班导师可选「手动录入」，不走工号查询。工号查不到时提示可改用手动录入。名单「来源」显示「手动录入」。学院含湘雅医学院（班导师不在教职工库）。
- **优秀班导师专干**：学办主任刘佳是计算机学院默认专干，林书衡已预置在 `state.yxbdsZg`。学办主任可「添加专干」。主任和专干都能查看、审核，并在角色端名单新增、编辑本学院申报。班导师只能看本人申请和已公布结果，没有审核按钮。批次启用且评选开始日期不晚于今天时，评选规则配置上显示「通知已发出」。优秀班导师名单和标兵按当前筛选导出，按钮写明「可导出历年名单」。

### 关键业务逻辑（已在原型中实现）

- **班导师名单**：工号查询自动带出教职工信息；选学院后联动带班班级；「新进青年教师 = 是」才显示青年教师类型；导入有进度和结果（含失败清单）；工具栏「下载导入模板」导出空表头（工号、姓名、性别、学院、联系电话、带班班级编号等）；导出可选列。
- **优秀班导师申请流程**：申请 → 学院审核（学办主任）→ 副书记审核 → 优秀班导师专干（学工部）审核 → 学工部审核 → 已通过；任一节点驳回即「未通过」。办理页有表单信息、抄送人、流程图、当前审批人、审批记录页签，同意/驳回都要填审批意见。
- **参评资格校验**（`js/mock/rules.js`）：
  - 批次需已启用，且在评选时间内；评选学年需属于该批次。
  - 同一批次不能重复提交；批次不允许时，兼任辅导员不能参评。
  - 任班导师时长取任职区间与评选学年 `[起始年-09-01, 结束年-08-31]` 的交集，按月差计算，不足即弹出「不符合参评资格」。
- **学院推荐名额**：学院审核同意时校验 `round(学院班导师总数 × 推荐名额比例%)`，超出时提示「推荐人数超过批次规定人数，无法同意」。
- **班级管理**：学工部管理员、学院班导师专干、辅导员在「管理班级 › 班导师列表」添加或移除班导师，会写入带班履历并同步「带班班级 / 带班数量」和移动端。添加时要选择学年和开始时间，结束时间可空（空表示至今），并按所选起止时间校验「一班一名、一人最多两班」。班导师在班级管理只能查看班级信息，不能新增、导入、编辑、删除或管理班级；默认勾选「我的带班」，只用于筛选。
- **津贴发放**：
  - 金额 = (其他班导师津贴 + 新进青年教师加发) × 周期倍数，带班数不参与计算。
  - 逐人审批链：待核对（班导师本人）→ 学办主任 → 副书记 → 学工部管理员 → 学工部领导 → 审批通过；驳回回到待核对。
  - 批次状态按人员状态自动汇总；学工部领导可查看「审批进度」（按学院统计）。

## 六、与线上/源码的差异和已知问题

1. **任职时长 12 个月永远无法满足（源码缺陷，原样保留）**：评选学年区间是 09-01 至次年 08-31，按月差最多只算 11 个月，所以规则选「12 个月」时没有人能通过。演示批次「2025-2026学年优秀班导师评选」用的是 9 个月。想复现这个问题，可以在「评选规则配置」里新增一个评选时间覆盖今天、任职时长选 12 个月的批次，再去申请。
2. **流程节点名称以线上流程图为准**：业务流程优化文档里写的是「学办主任审核 → 副书记审核并公示 → 事务办一级审核 → 事务办二级审核并公示」，线上低代码流程是「学院审核 → 副书记审核 → 优秀班导师专干（学工部）审核 → 学工部审核」。原型采用线上名称。
3. **节点与审核状态的对应是推断的**：工单节点对应名单审核状态 `shzt`（学院审核中 / 学院公示中 / 学工部审核中 / 学工部公示中 / 已通过 / 未通过），源码没有直接写明这个对应关系，原型是按状态含义推断的。
4. **学院字段**：线上优秀班导师表单的「学院」显示的是学院编码，原型显示学院名称，便于演示。
5. **津贴数据范围**：后端只对辅导员按本人过滤；原型里班导师角色也只能看到自己的那条记录，方便演示「班导师核对」环节。
6. **津贴辅导员/其他类型批次**：只展示批次列表，点「查看名单」只给提示，名单未实现（不在本次范围）。
7. **班级管理**：线上该页面当时打开为 404，原型按源码复刻管理端；管理班级弹窗的「学生列表」「班干部信息」「操作日志」做了简化，重点在「班导师列表」。班导师角色不进入该弹窗，在班级管理只能查看只读班级信息。
8. **移动端**：
   - 学工队伍名单的教职工卡片和源码一样不可点击（源码对教职工不进入详情）。
